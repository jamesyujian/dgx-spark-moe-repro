# 噪声与引用纪律（公告 §12 的精简版）

English：[`NOISE_POLICY.en.md`](NOISE_POLICY.en.md)（本文件为准）

## 1. 三类证据，三种可信度

| 类型 | 例子 | 可信度 | 引用纪律 |
|---|---|---|---|
| 确定性 / 精度 | 十轮内容投影 md5、逐题对错、Δlp、logprob 全等 | **高** | 可引绝对值，**必须写全栈身份**（机型/SM/版本/后端/dtype/TP） |
| 配对比值 | 后端 A vs B 的 −6.31 %、A/B 胜场 | **中** | 只引**比值 + 胜场 + p**，不引两侧绝对值；不同窗口的比值**不许相减** |
| 绝对吞吐 | 单跑 tok/s、某档并发吞吐 | **低** | 一律**中位数 + 极差 + 窗口**，并标"不可跨窗口比较" |

## 2. 三条已量化的噪声源

1. **NVFP4 的差异是内核非确定性，不是采样噪声**。`temperature=0` + 固定 seed 十轮仍翻转 5–7 题；同机 BF16 十轮逐字节全同（0 翻转）。两项排除实验：`VLLM_BATCH_INVARIANT=1` **起服失败**；`--enforce-eager` 后 Δlp **反升**。**2026-11-20 在第二台机型（PRO 4500 32 G）独立复核**：同服务三轮里 2–3 题文本变化、`code_bug` 由错改对（17/20→18/20）；而两机**首轮**内容投影 md5 逐字节相同（`74dc1260…`）。⇒ 该格不可作确定性参照，首轮一致不代表可复现。
2. **绝对吞吐会漂**：同机同栈 3 分钟窗口内可漂 ~18 %（先在 5080 节点量化）。
3. **A/B 配对缺真实回归正控制**：只能证明"差 ≥ 噪声底"，不能证明"能检出已知回归"。⇒ **分辨率下限 = 容差**。

## 3. 五条硬规则

1. 跨版本不相减（GSM8K 参照必须同版本同 TP）。
2. 跨窗口不比比值。
3. 量化路径不许写"赢 BF16"：Δ 小于容差一律写"不可区分"。
4. 样本量摊开写：1319 题单跑标准误 ≈ 1.0 pp ⇒ `±5 pp` 通过门作废。
5. 并发/吞吐只描述**曲线形状与拐点**，不描述"某档绝对性能好坏"。

## 4. 复现最小信息（缺一项，数字就不可归因）

`机型 + SM` ｜ `引擎版本（到 dev 串）` ｜ `MoE 后端（显式指定）` ｜ `TP/PP/DP` ｜ `dtype + 量化契约` ｜ `ctx / max-num-seqs / util / enforce-eager / batch-invariant` ｜ `prompt 集版本 + 判分脚本 + 每轮 md5`
